# 簡介

ReCodex 讓你在**官方 Codex 客戶端**裡直接用上訂閱額度 —— 不用手工維護 API Key,也不用自己拼設定。

它不是 Codex 的替代品,而是在官方客戶端之上工作:接管帳號與額度顯示,並把請求經由就近網關送到你訂閱對應的帳號。

## 適合誰

- 想在 Codex 裡直接開工,不想折騰 `base_url`、API Key 和網關參數。
- 在 Codex CLI、IDE 擴充、桌面端之間來回切,希望它們共用同一套設定。
- 需要隨時看清楚自己還剩多少額度、綁了哪些裝置。
- 偶爾要切回自己的 ChatGPT 帳號,切回來時不想重新登入一遍。

## 兩種使用方式

兩種方式**共用同一個帳號和同一份額度**,可以只裝一個,也可以都裝。

## 不會做什麼

- 不會把 ReCodex 說成 OpenAI 官方產品。
- 不承諾無限用量、零中斷或零風險。
- 不會要你在工單裡發送原始金鑰、授權碼或未脫敏日誌。
- 不會替你保管 ChatGPT 密碼 —— 登入走裝置授權,你在自己的瀏覽器裡批准。
