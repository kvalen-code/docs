# 簡介

ReCodex 面向希望直接使用 ChatGPT 客戶端和 Codex 開發工具、又不想手動維護 API Key 與複雜設定的使用者。

## 適合誰

- 需要在 ChatGPT 客戶端中工作，並希望透過一次授權快速開始。
- 使用 Codex CLI、IDE 擴充功能或桌面端，希望多個入口共用同一套託管設定。
- 需要集中查看訂閱、裝置、用量與帳單狀態。
- 遇到授權失效或更換裝置時，希望有清晰的恢復流程。

## 兩種使用方式

## ReCodex 幫你做什麼

ReCodex 負責產生授權入口、管理裝置工作階段、下發 Codex 所需的託管設定，並提供狀態、診斷和去敏日誌工具。你不需要向 ReCodex 提交自己的 ChatGPT 密碼，也不需要手動拼接閘道參數。

## 不會做什麼

- 不會把 ReCodex 描述為 OpenAI 官方產品。
- 不承諾無限用量、零中斷或零風險。
- 不要求你在支援工單中傳送原始金鑰、授權連結或未去敏日誌。
- 不在文件中公開內部帳號憑證與營運設定。
