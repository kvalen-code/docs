# 帳單

帳單頁面集中展示訂單、付款結果、訂閱生效狀態、兌換碼和發票資訊。金額、幣別、稅費與可用付款方式以結帳頁為準。

## 付款方式

ReCodex 可能根據地區和收款設定提供支付寶、微信支付、銀行卡或其他付款通道。結帳頁沒有顯示的方式即代表目前不可用。

## 訂單狀態

| 狀態 | 因應方式 |
| --- | --- |
| 待付款 | 返回結帳頁完成付款，過期訂單需重新建立 |
| 處理中 | 等待付款通道確認，不要重複付款 |
| 已付款 | 等待訂閱狀態更新；長時間未生效再聯繫支援 |
| 已關閉 | 訂單未完成或已取消，需要重新下單 |
| 已退款 | 查看退款記錄及原付款通道到帳進度 |

## 使用兌換碼

在帳戶中的兌換入口輸入完整兌換碼並確認。兌換成功後檢查訂閱或餘額變化；同一碼重複提交不會產生第二次權益。

## 發票

如結帳主體支援開立發票，可在帳單詳情提交抬頭和必要資訊。已開立發票訂單的退款與沖銷規則以申請頁面展示為準。

## 退款

是否可退款取決於方案類型、使用情況、購買時間、付款通道和最新服務條款。提交申請前，請準備訂單編號和問題描述，不要傳送支付密碼、完整銀行卡號或客戶端金鑰。

## 付款成功但方案未生效

1. 重新整理帳單與訂閱頁面。
2. 確認訂單狀態確為已付款，而不是處理中。
3. 登出後重新登入 ReCodex 帳戶。
4. 仍未恢復時提交工單，附訂單編號與付款時間，不附敏感憑證。

<Warning>
  任何支援人員都不應要求你提供支付密碼、ChatGPT 密碼、ReCodex 金鑰或裝置授權碼。
</Warning>
