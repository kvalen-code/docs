# 裝置

ReCodex 把 ChatGPT 客戶端授權工作階段和 Codex 登入機器關聯到你的帳戶。裝置頁面用於查看最近活動、撤銷舊工作階段和釋放方案裝置名額。

## 在哪裡查看

登入 [recodex.dev](https://recodex.dev)，進入裝置管理。列表通常包含裝置名稱、類型、建立時間、最近活動時間與狀態。

## 新增 ChatGPT 客戶端

從帳戶頁面產生動態授權連結，並只在目標裝置上開啟。完成後，該客戶端會作為授權工作階段顯示。授權連結本身不是長期裝置憑證。

## 新增 Codex 裝置

在新機器上安裝客戶端後執行：

```bash
recodex login
```

在瀏覽器批准裝置。登入完成後使用 `recodex status` 驗證訂閱與設定狀態。

## 達到裝置上限

`recodex login` 會列出目前裝置並讓你選擇要登出的舊裝置。撤銷工作階段後，舊裝置會在下次請求或校驗時失去存取權限。

## 主動撤銷

從網頁裝置列表選擇不再使用或不認識的裝置並撤銷。若撤銷的是目前的 Codex 裝置，也應在本機執行：

```bash
recodex logout
```

## 裝置被自動撤銷

密碼重設、安全策略、訂閱到期或異常登入可能觸發工作階段撤銷。確認帳戶安全後，重新產生 ChatGPT 授權連結或再次執行 `recodex login`。

<Tip>
  裝置名稱來自本機資訊，重裝系統或更改主機名稱後可能看起來像一台新裝置。
</Tip>
