# 裝置

每台透過桌面端或命令列登入過的機器,都會作為一台裝置關聯到你的帳戶。裝置頁面用於查看最近活動、撤銷不再使用的裝置、釋放名額。

## 在哪裡查看

登入 [recodex.dev](https://recodex.dev),進入裝置管理。列表通常包含裝置名稱、類型、建立時間、最近活動時間與狀態。

## 新增一台裝置

在 ReCodex 桌面端或命令列裡發起登入,客戶端會顯示一個授權碼;你在瀏覽器裡批准之後,這台機器就會作為裝置出現在列表裡。每個帳號最多同時授權 **3 台裝置**。

命令列的做法:

```bash
recodex login
recodex status
```

## 達到裝置上限

`recodex login` 會列出目前裝置並讓你選一台撤銷,撤銷後直接繼續本次登入。

桌面端會提示「裝置數已達上限」,你到網頁裝置管理撤銷一台即可 —— **撤銷之後不用重新登入**,客戶端的輪詢會自己走通。

## 主動撤銷

從網頁裝置列表選擇不再使用或不認識的裝置並撤銷。若撤銷的是你目前這台機器,也應在本機執行:

```bash
recodex logout
```

## 裝置被自動撤銷

密碼重設、安全策略、訂閱到期或異常登入可能觸發工作階段撤銷。這時 `recodex status` 會顯示「憑據已失效」。確認帳戶安全後,在桌面端面板重新登入,或再次執行 `recodex login`。

<Tip>
  裝置身分是持久的:同一台機器重新登入不會額外佔用名額。但重裝系統或更改主機名稱後,可能會被當成一台新裝置。
</Tip>
