# 邀請獎勵

邀請功能允許你分享專屬連結。被邀請使用者完成符合目前規則的訂單後，獎勵會按 ReCodex 帳戶頁顯示的政策結算。

## 取得邀請連結

登入 [recodex.dev](https://recodex.dev)，進入邀請或獎勵頁面，複製目前帳戶產生的專屬連結。不要手動修改連結中的邀請碼。

## 分享時說明什麼

- ReCodex 是獨立服務，不是 OpenAI 官方產品。
- 方案、價格與權益以被邀請人開啟的正式頁面為準。
- 不承諾無限使用、永不封號或固定收益。

## 獎勵狀態

| 狀態 | 含義 |
| --- | --- |
| 待確認 | 訂單尚在付款、風控或結算週期中 |
| 已發放 | 獎勵已經計入帳戶可用權益 |
| 無效 | 訂單取消、退款、重複歸因或不符合活動規則 |

## 獎勵如何使用

獎勵可能以訂閱時長、方案權益或帳戶額度形式發放，具體類型和有效期以帳戶記錄為準。除非活動頁面明確說明，獎勵不等同於可提現現金。

## 下單後沒有獎勵

先確認對方是在有效邀請工作階段中完成符合條件的首筆訂單，並等待訂單結束處理中狀態。仍未結算時提交工單，提供邀請記錄與訂單編號，不提供付款憑證。

<Note>
  活動比例、結算週期和適用方案可能調整，帳戶頁面中的最新規則具有優先權。
</Note>
