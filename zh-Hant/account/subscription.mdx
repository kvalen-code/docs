# 訂閱

ReCodex 方案決定可授權的客戶端、裝置數量和可使用額度。可售方案、價格與庫存會變化，以 [recodex.dev](https://recodex.dev) 帳戶頁面顯示為準。

## 方案類型

<CardGroup cols={2}>
  <Card title="獨享方案" icon="user">
    為單一使用者分配獨立訂閱資源，適合穩定、高頻使用。
  </Card>

  <Card title="共乘方案" icon="users">
    多人共用訂閱額度，適合希望降低成本並接受共用視窗限制的使用者。
  </Card>
</CardGroup>

帳戶中可能展示 ChatGPT Plus 獨享、ChatGPT Pro 不同額度檔位，以及不同人數的共乘方案。只有結帳頁目前可購買的方案才代表正式供應。

## 訂閱狀態

| 狀態 | 含義 |
| --- | --- |
| `active` | 訂閱有效，可以依方案規則授權裝置 |
| `pending` | 訂單或付款仍在確認，不代表已經生效 |
| `expired` | 已到期，需要續費或購買新方案 |
| `cancelled` | 已取消後續續費；目前權益是否繼續以帳戶頁為準 |
| `suspended` | 因安全、付款或合規原因暫停，需要聯繫支援 |

## 用量視窗

額度按兩個視窗計算:**5 小時**和**7 天**,各自到期後自動恢復。桌面端面板和命令列讀的是同一份伺服器資料。

```bash
recodex usage --refresh
```

近 5 小時沒有用量時,上游不會回傳 5 小時視窗,介面上就不顯示 —— 這是正常的,不是掉資料。

## 續費與到期

續費成功後，以帳戶頁面的有效期和狀態更新為準。到期後，新的授權和請求可能停止；已經開啟的客戶端也可能在下次校驗時要求重新授權。

## 更換方案

可否升級、降級、變更共乘人數或同時持有多個方案，取決於目前帳戶頁面提供的操作。涉及差價與有效期時，在確認訂單前仔細核對摘要。

<Note>
  文件不固定展示價格和庫存，以免與即時結帳資訊不一致。
</Note>
