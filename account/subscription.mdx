# 订阅

ReCodex 套餐决定可授权的客户端、设备数量和可使用额度。可售方案、价格与库存会变化，以 [recodex.dev](https://recodex.dev) 账户页面显示为准。

## 套餐类型

<CardGroup cols={2}>
  <Card title="独享套餐" icon="user">
    为单个用户分配独立订阅资源，适合稳定、高频使用。
  </Card>

  <Card title="拼车套餐" icon="users">
    多人共享订阅额度，适合希望降低成本并接受共享窗口限制的用户。
  </Card>
</CardGroup>

账户中可能展示 ChatGPT Plus 独享、ChatGPT Pro 不同额度档位，以及不同人数的拼车方案。只有结账页当前可购买的方案才代表正式供应。

## 订阅状态

| 状态 | 含义 |
| --- | --- |
| `active` | 订阅有效，可以按套餐规则授权设备 |
| `pending` | 订单或支付仍在确认，不代表已经生效 |
| `expired` | 已到期，需要续费或购买新套餐 |
| `cancelled` | 已取消后续续费；当前权益是否继续以账户页为准 |
| `suspended` | 因安全、支付或合规原因暂停，需要联系支持 |

## 用量窗口

ChatGPT 与 Codex 的额度可能按 5 小时、每日或滚动周期恢复。`recodex status` 和 Dashboard 展示服务端确认的窗口；不要把暂时的本地缓存当作最终结果。

```bash
recodex status
```

## 续费与到期

续费成功后，以账户页面的有效期和状态更新为准。到期后，新的授权和请求可能停止；已经打开的客户端也可能在下次校验时要求重新授权。

## 更换方案

可否升级、降级、变更拼车人数或同时持有多个方案，取决于当前账户页面提供的操作。涉及差价与有效期时，在确认订单前仔细核对摘要。

<Note>
  文档不固定展示价格和库存，以免与实时结账信息不一致。
</Note>
