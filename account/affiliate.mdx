# 邀请奖励

邀请功能允许你分享专属链接。被邀请用户完成符合当前规则的订单后，奖励会按 ReCodex 账户页显示的政策结算。

## 获取邀请链接

登录 [recodex.dev](https://recodex.dev)，进入邀请或奖励页面，复制当前账户生成的专属链接。不要手工修改链接中的邀请码。

## 分享时说明什么

- ReCodex 是独立服务，不是 OpenAI 官方产品。
- 套餐、价格与权益以被邀请人打开的正式页面为准。
- 不承诺无限使用、永不封号或固定收益。

## 奖励状态

| 状态 | 含义 |
| --- | --- |
| 待确认 | 订单尚在支付、风控或结算周期中 |
| 已发放 | 奖励已经计入账户可用权益 |
| 无效 | 订单取消、退款、重复归因或不符合活动规则 |

## 奖励如何使用

奖励可能以订阅时长、套餐权益或账户额度形式发放，具体类型和有效期以账户记录为准。除非活动页面明确说明，奖励不等同于可提现现金。

## 下单后没有奖励

先确认对方是在有效邀请会话中完成符合条件的首笔订单，并等待订单结束处理中状态。仍未结算时提交工单，提供邀请记录与订单号，不提供付款凭据。

<Note>
  活动比例、结算周期和适用套餐可能调整，账户页面中的最新规则具有优先级。
</Note>
