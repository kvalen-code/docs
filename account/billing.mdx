# 账单

账单页面集中展示订单、支付结果、订阅生效状态、兑换码和发票信息。金额、币种、税费与可用支付方式以结账页为准。

## 支付方式

ReCodex 可能根据地区和收款配置提供支付宝、微信支付、银行卡或其他支付通道。结账页没有显示的方式即代表当前不可用。

## 订单状态

| 状态 | 应对方式 |
| --- | --- |
| 待支付 | 返回结账页完成付款，过期订单需重新创建 |
| 处理中 | 等待支付渠道确认，不要重复付款 |
| 已支付 | 等待订阅状态更新；长时间未生效再联系支持 |
| 已关闭 | 订单未完成或已取消，需要重新下单 |
| 已退款 | 查看退款记录及原支付渠道到账进度 |

## 使用兑换码

在账户中的兑换入口输入完整兑换码并确认。兑换成功后检查订阅或余额变化；同一码重复提交不会产生第二次权益。

## 发票

如结账主体支持开票，可在账单详情提交抬头和必要信息。已开票订单的退款与红冲规则以申请页面展示为准。

## 退款

是否可退款取决于套餐类型、使用情况、购买时间、支付渠道和最新服务条款。提交申请前，请准备订单号和问题描述，不要发送支付密码、完整银行卡号或客户端密钥。

## 支付成功但套餐未生效

1. 刷新账单与订阅页面。
2. 确认订单状态确为已支付，而不是处理中。
3. 退出后重新登录 ReCodex 账户。
4. 仍未恢复时提交工单，附订单号与支付时间，不附敏感凭据。

<Warning>
  任何支持人员都不应要求你提供支付密码、ChatGPT 密码、ReCodex 密钥或设备授权码。
</Warning>
