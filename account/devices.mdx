# 设备

ReCodex 把 ChatGPT 客户端授权会话和 Codex 登录机器关联到你的账户。设备页面用于查看最近活动、撤销旧会话和释放套餐设备名额。

## 在哪里查看

登录 [recodex.dev](https://recodex.dev)，进入设备管理。列表通常包含设备名称、类型、创建时间、最近活动时间与状态。

## 添加 ChatGPT 客户端

从账户页面生成动态授权链接，并只在目标设备上打开。完成后，该客户端会作为授权会话显示。授权链接本身不是长期设备凭据。

## 添加 Codex 设备

在新机器上安装客户端后运行：

```bash
recodex login
```

在浏览器批准设备。登录完成后使用 `recodex status` 验证订阅与配置状态。

## 达到设备上限

`recodex login` 会列出当前设备并让你选择要退出的旧设备。撤销会话后，旧设备会在下次请求或校验时失去访问权限。

## 主动撤销

从网页设备列表选择不再使用或不认识的设备并撤销。若撤销的是当前 Codex 设备，也应在本机运行：

```bash
recodex logout
```

## 设备被自动撤销

密码重置、安全策略、订阅到期或异常登录可能触发会话撤销。确认账户安全后，重新生成 ChatGPT 授权链接或再次运行 `recodex login`。

<Tip>
  设备名称来自本机信息，重装系统或更改主机名后可能看起来像一台新设备。
</Tip>
