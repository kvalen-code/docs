# 常见问题

<AccordionGroup>
  <Accordion title="ReCodex 和官方 Codex 是什么关系?">
    ReCodex **不替换**官方 Codex,而是在它之上工作:接管账号与额度显示,并把请求经由就近网关送到你订阅对应的账号。 所以你的机器上需要先装好官方 Codex 客户端。
  </Accordion>

  <Accordion title="桌面端和命令行要装哪个?">
    看习惯。两者**共用同一个账号和同一份额度**,可以只装一个,也可以都装。 图形界面用桌面端;习惯终端、或者要写脚本的话用命令行。
  </Accordion>

  <Accordion title="需要自己的 ChatGPT 账号或 API Key 吗?">
    不需要向 ReCodex 提交 ChatGPT 密码,也不用手工填 API Key。可用资源由你的 ReCodex 套餐决定。
  </Accordion>

  <Accordion title="登录之后为什么还要重启一次?">
    官方 Codex 进程是在你登录**之前**启动的,读不到新写入的配置和密钥。 桌面端面板上点「立即重启生效」即可;命令行下需要新开一个终端(Windows 上尤其如此)。
  </Accordion>

  <Accordion title="最多能登录几台设备?">
    3 台。到上限时,命令行会列出设备让你选一台撤销,桌面端会提示你去[设备管理](https://recodex.dev/dashboard/devices)撤销。 撤销之后**不用重新登录** —— 客户端的轮询会自己走通。

    同一台机器重新登录不会额外占名额:设备身份是持久的。
  </Accordion>

  <Accordion title="额度是怎么算的?为什么有时看不到 5 小时窗口?">
    额度分 5 小时和 7 天两个窗口,数据是**服务端权威**的,桌面端和 `recodex usage` 读的是同一份。

    近 5 小时没有用量时,上游不返回这个窗口,界面上就不显示 —— 这是正常的,不是丢数据。
  </Accordion>

  <Accordion title="为什么显示「数据可能不是最新的」?">
    额度是快照不是实时值。超过 5 分钟没更新就会这么标注,同时客户端会在后台自动补一次刷新; 你也可以手动点「刷新额度」或运行 `recodex usage --refresh` 立刻更新。
  </Accordion>

  <Accordion title="可以切回我自己的 ChatGPT 账号吗?">
    可以。桌面端面板上有「官方模式」,一键切过去,新对话就走你自己的账号;切回来时 ReCodex 的配置原样恢复,**不用重新登录**。

    切到官方模式时,ReCodex 的 provider 定义会保留在配置里(只是不再作为默认)—— 这样之前用 ReCodex 建的历史对话才打得开。
  </Accordion>

  <Accordion title="ReCodex 会覆盖我原有的 Codex 配置吗?">
    不会。它只写 `# >>> recodex managed block` 标记之间的那一段,你自己的配置原样保留。 `recodex logout` 或 `uninstall` 会把登录前的配置还原回去,也不会动你 `~/.codex` 里的会话、记忆等数据。
  </Accordion>

  <Accordion title="感觉变慢了怎么办?">
    换个网关:`recodex gateways auto` 自动选延迟最低的,或者在桌面端面板上点「用最快网关」。 `recodex gateways` 可以看到各线路的实测延迟。
  </Accordion>

  <Accordion title="遇到 429 就是账号被封吗?">
    不是。429 通常是额度或频率限制,等窗口恢复即可。跑一次 `recodex doctor`,它会区分是订阅问题还是配置问题。
  </Accordion>

  <Accordion title="自动更新安全吗?">
    更新只接受带**有效签名**的发布清单,并在替换前核对哈希。签名验不过就直接拒绝, 不会退而求其次装一个来源不明的二进制。
  </Accordion>

  <Accordion title="ReCodex 是 OpenAI 官方产品吗?">
    不是。ReCodex 是独立服务;OpenAI、ChatGPT 和 Codex 的产品名称及商标归其权利人所有。
  </Accordion>

  <Accordion title="找客服时该提供什么?">
    发生时间(到分钟)、操作系统、`recodex version`、`recodex doctor --json` 的输出,以及最短复现步骤。

    **不要**提供密码、原始密钥、设备授权码或未脱敏日志 —— 客服不会索取这些。
  </Accordion>
</AccordionGroup>
