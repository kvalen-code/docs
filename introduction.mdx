# 简介

ReCodex 面向希望直接使用 ChatGPT 客户端和 Codex 开发工具、又不想手工维护 API Key 与复杂配置的用户。

## 适合谁

- 需要在 ChatGPT 客户端中工作，并希望通过一次授权快速开始。
- 使用 Codex CLI、IDE 扩展或桌面端，希望多入口共享同一套托管配置。
- 需要集中查看订阅、设备、用量与账单状态。
- 遇到授权失效或设备更换时，希望有清晰的恢复流程。

## 两种使用方式

  <Card title="ChatGPT 客户端" icon="comments">
    登录 ReCodex 后获取动态授权链接，在客户端完成授权。
  </Card>

  <Card title="Codex" icon="code">
    运行 `recodex login`，在浏览器批准设备，由 ReCodex写入托管配置。
  </Card>

## ReCodex 帮你做什么

ReCodex 负责生成授权入口、管理设备会话、下发 Codex 所需的托管配置，并提供状态、诊断和脱敏日志工具。你不需要向 ReCodex 提交自己的 ChatGPT 密码，也不需要手动拼接网关参数。

## 不会做什么

- 不会把 ReCodex 描述为 OpenAI 官方产品。
- 不承诺无限用量、零中断或零风险。
- 不要求你在支持工单中发送原始密钥、授权链接或未脱敏日志。
- 不在文档中公开内部账号凭据与运营配置。
