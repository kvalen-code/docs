# 简介

ReCodex 让你在**官方 Codex 客户端**里直接用上订阅额度 —— 不用手工维护 API Key,也不用自己拼配置。

它不是 Codex 的替代品,而是在官方客户端之上工作:接管账号与额度显示,并把请求经由就近网关送到你订阅对应的账号。

## 适合谁

- 想在 Codex 里直接开工,不想折腾 `base_url`、API Key 和网关参数。
- 在 Codex CLI、IDE 扩展、桌面端之间来回切,希望它们共用同一套配置。
- 需要随时看清楚自己还剩多少额度、绑了哪些设备。
- 偶尔要切回自己的 ChatGPT 账号,切回来时不想重新登录一遍。

## 两种使用方式

两种方式**共用同一个账号和同一份额度**,可以只装一个,也可以都装。

## 不会做什么

- 不会把 ReCodex 说成 OpenAI 官方产品。
- 不承诺无限用量、零中断或零风险。
- 不会要你在工单里发送原始密钥、授权码或未脱敏日志。
- 不会替你保管 ChatGPT 密码 —— 登录走设备授权,你在自己的浏览器里批准。
