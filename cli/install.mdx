# 安装 CLI

命令行和[桌面端](/quickstart)用的是**同一个账号、同一份额度**,按习惯选一个即可,也可以两个都装。

<Note>
  无论用哪种方式,你的机器上都需要先装好官方 **Codex 桌面客户端** —— ReCodex 是在它之上工作的。
</Note>

## 一键安装(推荐)

<CodeGroup>

```bash macOS / Linux
curl -fsSL https://recodex.dev/install.sh | bash
```

```powershell Windows
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://recodex.dev/install.ps1 | iex"
```

</CodeGroup>

脚本做三件事:按平台选二进制、**校验 sha256**、装到 PATH 上。

<Warning>
  校验不是可选项。`curl | sh` 这种装法等于把「装什么」完全交给网络 —— 所以脚本在哈希对不上时会**直接中止**,不会退而求其次装上去。
</Warning>

可以用环境变量改装到哪里:

```bash
RECODEX_INSTALL_DIR=~/bin curl -fsSL https://recodex.dev/install.sh | bash
```

验证:

```bash
recodex version
```

## 手动下载

也可以到 [recodex.dev/download](https://recodex.dev/download) 直接取二进制, 和校验文件 `SHA256SUMS` 一起下载并自行核对,然后放进 `PATH`。

<Warning>
  不要从聊天记录、网盘或未知镜像取客户端。正式下载地址与校验信息以 recodex.dev 为准。
</Warning>

## 安装官方 Codex

ReCodex 需要官方 Codex 客户端在场。若还没装:

<CodeGroup>

```bash macOS / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

```powershell Windows
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

</CodeGroup>

装完之后可以让 ReCodex 确认一遍:

```bash
recodex install check
```

它能识别从\*\*应用商店(MSIX)\*\*安装的版本 —— 那种装法不在 `Programs` 目录下,单看常规路径会误判成"没装"。

## IDE 与桌面端

Codex 的 IDE 扩展和桌面端读的是同一份 `~/.codex` 配置。完成 `recodex login` 后, 请**重启**已经打开的 IDE 或桌面端,让它重新加载环境变量与托管配置。

## 升级

```bash
recodex update
```

只接受带有效签名的发布清单;签名验不过会直接拒绝,不会装来源不明的二进制。

Codex 本身用 OpenAI 官方安装器或包管理器升级。

## 卸载

```bash
recodex uninstall
```

会先注销当前设备、还原登录前的 Codex 配置,再删除 ReCodex 的客户端数据。 你自己的 `~/.codex` 数据(会话、记忆、日志)不受影响。程序文件可随后手动删除。
