# Установка CLI

Командная строка и [десктопный клиент](/ru/quickstart) используют **один аккаунт и одну квоту**. Можно поставить что-то одно или оба.

<Note>
  В любом случае на машине должен быть установлен официальный **десктопный клиент Codex** — ReCodex работает поверх него.
</Note>

## Установка одной командой (рекомендуется)

<CodeGroup>

```bash macOS / Linux
curl -fsSL https://recodex.dev/install.sh | bash
```

```powershell Windows
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://recodex.dev/install.ps1 | iex"
```

</CodeGroup>

Скрипт делает три вещи: выбирает бинарник под платформу, **проверяет sha256** и ставит его в PATH.

<Warning>
  Проверка хеша — не опция. `curl | sh` целиком доверяет сети то, что будет установлено, поэтому при несовпадении хеша скрипт **прерывается** и ничего не ставит.
</Warning>

Каталог установки можно задать переменной окружения:

```bash
RECODEX_INSTALL_DIR=~/bin curl -fsSL https://recodex.dev/install.sh | bash
```

Проверка:

```bash
recodex version
```

## Ручная загрузка

Можно взять бинарник напрямую на [recodex.dev/download](https://recodex.dev/download), скачать рядом файл `SHA256SUMS`, сверить хеш самостоятельно и положить бинарник в `PATH`.

<Warning>
  Не скачивайте клиент из переписок, файлообменников или неизвестных зеркал. Официальные адреса и контрольные суммы — только на recodex.dev.
</Warning>

## Установка официального Codex

ReCodex требует, чтобы официальный клиент Codex был на месте. Если его ещё нет:

<Note>
  Официальная страница `openai.com/chatgpt/download` открывается не везде. Прямые ссылки есть на [recodex.dev/download](https://recodex.dev/download) — открывать сайт OpenAI не требуется.
</Note>

**Десктопный клиент** (для тех, кто работает в графическом интерфейсе):

Это **шаг 1** на [recodex.dev/download](https://recodex.dev/download) — на обеих платформах загрузка начинается по клику:

- **Windows**: приложение есть только в Microsoft Store, отдельного установщика нет. На странице загрузки лежит оригинальный пакет из магазина (`.msixbundle`): скачайте и запустите двойным щелчком — установит системный «Установщик приложений». Нужна Windows 10 версии 2004 или новее. Для машин на ARM64 выбирайте вариант arm64 — пакет другой архитектуры не установится.
- **macOS**: официально есть только `ChatGPT.dmg`; на странице лежит тот же файл с указанной sha256.

Оба пакета мы только раздаём: не распаковываем, не изменяем и не переподписываем.

**Codex для командной строки** (если хватает терминала):

<CodeGroup>

```bash macOS / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

```powershell Windows
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

</CodeGroup>

После установки можно попросить ReCodex это подтвердить:

```bash
recodex install check
```

Он распознаёт установку из **магазина (MSIX)** — такая установка лежит не в `Programs`, и по обычным путям её легко принять за отсутствующую.

## IDE и десктоп

Расширение IDE и десктопный Codex читают тот же `~/.codex`. После `recodex login` **перезапустите** уже открытые IDE и десктопный клиент, чтобы они перечитали переменные окружения и конфигурацию.

## Обновление

```bash
recodex update
```

Принимается только манифест релиза с действительной подписью; при неудачной проверке обновление отклоняется, а не подменяется бинарником неизвестного происхождения.

Сам Codex обновляйте официальным установщиком OpenAI или пакетным менеджером.

## Удаление

```bash
recodex uninstall
```

Сначала отзывает текущее устройство, возвращает конфигурацию Codex к состоянию до входа, затем удаляет данные клиента ReCodex. Ваши собственные данные в `~/.codex` (сессии, память, журналы) не затрагиваются. Файл программы можно удалить вручную.
