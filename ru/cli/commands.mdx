# Справочник команд

## Использование

```text
recodex [--lang zh|en] [--api URL] <command>
```

## Обзор подкоманд

| Команда | Назначение |
| --- | --- |
| `recodex login` | Вход по коду устройства, запись конфигурации и учётных данных |
| `recodex logout` | Отзыв текущего устройства и восстановление исходной конфигурации |
| `recodex uninstall` | Выход, восстановление конфигурации и удаление всего состояния клиента ReCodex |
| `recodex status` | Статус входа, конфигурации, подписки и расхода |
| `recodex refresh` | Повторное получение управляемой конфигурации без повторного входа |
| `recodex update` | Обновление программы из подписанного манифеста релизов |
| `recodex doctor` | Диагностика Codex, управляемой конфигурации и шлюза |
| `recodex doctor --fix` | Попытка исправить безопасно исправимые проблемы и повторная диагностика |
| `recodex doctor --json` | Обезличенный JSON для автоматизации |
| `recodex logs --limit N` | Последние N обезличенных диагностических записей, по умолчанию 50 |
| `recodex version` | Версия клиента |

## Типичный сценарий

```bash
# Первый вход
recodex login

# Проверка статуса
recodex status

# Автоматическая диагностика
recodex doctor

# Обновление управляемой конфигурации
recodex refresh

# Безопасный выход с восстановлением конфигурации
recodex logout
```

## Глобальные параметры

### `--lang zh|en`

Язык вывода для текущей команды. По умолчанию — китайский.

```bash
recodex --lang en status
```

### `--api URL`

Переопределяет корневой адрес API ReCodex — только для авторизованных тестовых, предрелизных или саморазмещённых окружений. Обычным пользователям менять не нужно.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `RECODEX_LANG` | Язык вывода по умолчанию: `zh` или `en` |
| `RECODEX_API` | Переопределение адреса API; обычным пользователям — оставить как есть |

## Логи

```bash
recodex logs --limit 50
```

Вывод логов обезличивается, но перед отправкой в поддержку всё равно проверьте, нет ли там названий проектов, путей к файлам или другой информации, которой вы не хотите делиться.
