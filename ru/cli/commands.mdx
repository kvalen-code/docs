# Справочник команд

## Использование

```text
recodex [--lang zh|en] [--api URL] <команда>
```

## Аккаунт и состояние

| Команда | Назначение |
| --- | --- |
| `recodex login` | Вход через авторизацию устройства в браузере; пишет управляемую конфигурацию и учётные данные |
| `recodex status` | Статус входа, время выдачи, текущий шлюз, управляемость конфигурации, доступность шлюза и квота |
| `recodex account [--json]` | Почта аккаунта, тип (выделенный/общий) и тариф |
| `recodex usage [--refresh] [--json]` | Доступная квота, расход, время данных и окна 5 ч / 7 дней |
| `recodex logout` | Отозвать это устройство и вернуть конфигурацию Codex к состоянию до входа |

<Note>
  Строка «вход» в `status` показывает **ответ сервера**: если устройство отозвано на сервере, будет «учётные данные недействительны», а не «да» по локальному файлу. При проблемах с сетью ложного вывода о недействительности не будет.
</Note>

## Шлюзы

| Команда | Назначение |
| --- | --- |
| `recodex gateways [list]` | Все шлюзы: задержка, состояние и отметка выбранного |
| `recodex gateways test` | Повторный замер задержек |
| `recodex gateways use <id>` | Переключиться на указанный шлюз, например `recodex gateways use jp` |
| `recodex gateways auto` | Выбрать самый быстрый исправный шлюз |

```text
$ recodex gateways
jp      Япония прямой      53ms   healthy
sg      Сингапур прямой    31ms   healthy selected
jpcf    Япония CF          63ms   healthy
sgcf    Сингапур CF        45ms   healthy
```

## Установка и диагностика

| Команда | Назначение |
| --- | --- |
| `recodex install check` | Проверка предпосылок; распознаёт Codex, установленный из магазина (MSIX) |
| `recodex install repair` | Починить управляемую конфигурацию Codex |
| `recodex doctor` | Проверка по пунктам: установка клиента, конфигурация, вход, ключ, шлюз, подписка и доступность Codex |
| `recodex doctor --fix` | Сначала безопасные автопочинки, затем повторная проверка |
| `recodex doctor --json` | То же, но JSON (`schema_version` / `ok` / `checks`) — для скриптов и поддержки |
| `recodex refresh` | Перезапросить управляемую конфигурацию без повторного входа |
| `recodex logs [--limit N]` | Последние N обезличенных записей, по умолчанию 50 |

## Обслуживание

| Команда | Назначение |
| --- | --- |
| `recodex update` | Безопасное обновление из **подписанного** манифеста релиза |
| `recodex version` | Версия клиента |
| `recodex uninstall` | Отозвать устройство, вернуть конфигурацию и удалить все данные клиента ReCodex |

<Note>
  `recodex update` принимает только манифест с действительной подписью. Если подпись не проходит проверку — обновление отклоняется, а не подменяется бинарником неизвестного происхождения.
</Note>

## Типовые сценарии

```bash
# первый вход
recodex login

# состояние и квота
recodex status

# при проблемах — самодиагностика с автопочинкой
recodex doctor --fix

# переключиться на более быстрый шлюз
recodex gateways auto

# выйти и вернуть исходную конфигурацию
recodex logout
```

## Глобальные параметры

### `--lang zh|en`

Язык вывода текущей команды. По умолчанию китайский.

```bash
recodex --lang en status
```

### `--api URL`

Переопределяет корневой адрес API ReCodex. Только для авторизованных тестовых или self-hosted сред. Обычным пользователям менять не нужно.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `RECODEX_LANG` | Язык вывода по умолчанию: `zh` или `en` |
| `RECODEX_API` | Переопределение корневого адреса API; обычно оставляйте по умолчанию |
| `RECODEX_KEY` | Записывается клиентом при входе, Codex использует его для доступа к шлюзу. **Вручную не менять** |

<Warning>
  В Windows `RECODEX_KEY`, записанный при `recodex login`, **не виден уже открытому** терминалу — откройте новое окно. Поэтому сразу после входа `doctor` может жаловаться на ключ, а в новом терминале всё в порядке.
</Warning>

## Журнал

```bash
recodex logs --limit 50
```

Вывод — обезличенные строки JSON: только имя команды, результат, версия и ОС, без ключей:

```json
{"time":"2026-08-20T09:11:24Z","event":"command_finished","command":"doctor","result":"success","version":"1.2.55","os":"windows"}
```
