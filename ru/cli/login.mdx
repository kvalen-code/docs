# Вход и авторизация

У клиента ChatGPT и Codex разные точки входа. Первый использует динамические ссылки авторизации ReCodex, второй — device flow команды `recodex login`.

## Авторизация клиента ChatGPT

<Steps>
  <Step title="Войдите в аккаунт">
    Откройте [recodex.dev](https://recodex.dev) и войдите.
  </Step>
  <Step title="Выберите авторизацию ChatGPT">
    Запустите авторизацию клиента на странице аккаунта — система создаст одноразовую динамическую ссылку.
  </Step>
  <Step title="Откройте на целевом устройстве">
    Открывайте ссылку только на устройстве, где планируете использовать ChatGPT, и завершите подтверждение по подсказкам.
  </Step>
  <Step title="Вернитесь в клиент">
    После авторизации вернитесь в клиент ChatGPT. Если статус не обновился, закройте и снова откройте его.
  </Step>
</Steps>

<Warning>
  ReCodex никогда не попросит прислать пароль от ChatGPT через поддержку. Динамические ссылки авторизации также нельзя никому передавать.
</Warning>

## Вход устройства Codex

```bash
recodex login
```

В терминале появятся код и адрес подтверждения, браузер откроется автоматически. Войдите в ReCodex, подтвердите тариф и текущее устройство, затем дождитесь сообщения об успехе в терминале.

### Браузер не открылся

Скопируйте адрес подтверждения из терминала в браузер. Используйте только адрес из текущего запуска `recodex login`, а не старые ссылки из скриншотов инструкций.

### Достигнут лимит устройств

Клиент покажет список зарегистрированных устройств. Введите номер старого устройства для выхода — ReCodex отозвёт старый сеанс и продолжит текущий вход; введите `q`, чтобы отменить.

### Конфигурация записана, но ошибка остаётся

Если терминал просит перезапуск, полностью закройте и снова откройте терминал, IDE или десктоп, затем выполните:

```bash
recodex status
recodex doctor
```

## Обновление управляемой конфигурации

```bash
recodex refresh
```

Когда на сервере меняются узлы или параметры, `refresh` заново получает конфигурацию без повторного входа и обновления клиента.

## Выход

```bash
recodex logout
```

ReCodex постарается отозвать сеанс на сервере, удалит сохранённые учётные данные и восстановит резервную копию конфигурации Codex, сделанную до входа. Если сеть временно недоступна, локальное восстановление всё равно выполнится.
