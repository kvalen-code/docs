# Устранение неполадок

Сначала зафиксируйте время ошибки и операционную систему, затем начните с базового статуса — не переустанавливайте всё подряд и не раскрывайте учётные данные.

```bash
recodex status
recodex doctor
```

## Не устанавливается

### Не найден `recodex`

Убедитесь, что программа находится в `PATH`, откройте новый терминал и выполните `recodex version`. На Windows также проверьте, что браузер не переименовал и не поместил файл в карантин.

### Не найден `codex`

macOS / Linux:

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Windows:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

## Ошибка авторизации ChatGPT

- Сгенерируйте ссылку заново из текущего сеанса ReCodex.
- Открывайте её только на целевом устройстве в доверенном браузере.
- Если ссылка истекла, уже использована или отменена — создайте новую.
- Если клиент не обновился — полностью закройте и откройте его заново.
- Не вставляйте ссылки авторизации в тикеты поддержки.

## `recodex login` не завершается

- Браузер не открылся: используйте адрес из вывода текущего запуска.
- Код истёк: запустите `recodex login` заново.
- Лимит устройств: отключите старое устройство по подсказке или отзовите его на странице устройств.
- После подтверждения терминал всё ещё ждёт: не закрывайте терминал, проверьте сеть и повторите процедуру.

## Codex возвращает 401 или 403

Сначала выполните:

```bash
recodex status
recodex doctor
```

401 или истёкшие учётные данные обычно лечатся повторным `recodex login`. 403 может быть связан с подпиской, балансом, конфигурацией или состоянием вышестоящего аккаунта — не считайте каждый 403 блокировкой.

## 429 или исчерпан лимит

429 обычно означает ограничение частоты или окна расхода. Проверьте Dashboard и `recodex status`, дождитесь восстановления окна. Не повторяйте запросы непрерывно.

## Конфликт конфигурации

```bash
recodex doctor --fix
```

`--fix` исправляет только то, что безопасно исправить автоматически. Если сообщается о дублирующихся ключах в `config.toml`, сначала сделайте резервную копию и удалите поля, которые вы добавили вручную и которые дублируют управляемый блок ReCodex.

## Проблемы с устройствами

На странице устройств проверьте, есть ли текущая машина в списке и обновляется ли последняя активность. После отзыва текущего устройства нужно заново авторизовать ChatGPT или повторить `recodex login`.

## Оплата прошла, но подписка недоступна

Убедитесь, что заказ не в статусе обработки, обновите страницы оплаты и подписки, затем перезайдите в аккаунт. Если не помогло — отправьте номер заказа, время оплаты и статус со страницы, без платёжных паролей и полных платёжных документов.

## Сбор обезличенной диагностики

```bash
recodex doctor --json
recodex logs --limit 50
```

JSON и логи описывают стабильное состояние и недавние операции. Перед отправкой проверьте их вручную на пути к файлам, названия проектов и другую личную информацию.

## Всё ещё не работает?

В обращении в поддержку укажите: время инцидента (с точностью до минуты), ОС, `recodex version`, обезличенную категорию ошибки и минимальные шаги воспроизведения.

<Warning>
  Не отправляйте исходные ключи, коды устройств, ссылки авторизации ChatGPT, пароли, строки подключения к базам данных и необезличенные логи.
</Warning>
