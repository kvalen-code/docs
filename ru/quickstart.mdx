# Быстрый старт

У ReCodex два способа работы. Оба используют **один аккаунт и одну квоту** — выбирайте по привычке:

- **Десктопный клиент (рекомендуется)**: установили, открыли, работаете. Аккаунт и квота видны прямо в интерфейсе Codex.
- **Командная строка**: если привыкли к терминалу — `recodex` умеет вход, квоту, выбор шлюза и самодиагностику.

<Note>
  Для обоих способов на машине уже должен стоять официальный **десктопный клиент Codex** — ReCodex работает поверх него, а не вместо него.

  Официальная страница загрузки открывается не везде — это **шаг 1** на [recodex.dev/download](https://recodex.dev/download): и для Windows, и для macOS загрузка начинается по клику (наши зеркала оригинальных установщиков, с указанной sha256).
</Note>

## Способ 1: десктопный клиент

<Steps>
  <Step title="Скачайте установщик">
    На [recodex.dev/download](https://recodex.dev/download) выберите свою систему:

    - Windows: `ReCodex-<версия>-windows-x64-setup.exe`
    - macOS (Apple Silicon): `ReCodex-<версия>-macos-arm64.dmg`

    Страница сама поставит вашу систему первой.
  </Step>
  <Step title="Установите и запустите">
    В Windows ставится в `%LOCALAPPDATA%\Programs\ReCodex`, создаёт ярлыки на рабочем столе и в меню «Пуск». После запуска клиент сам находит установленный Codex и берёт интерфейс на себя.

    В macOS перетащите ReCodex в «Программы». Если при первом запуске система пишет, что **разработчик не проверен**, нажмите на приложение правой кнопкой в Finder и выберите «Открыть», либо выполните:

    ```bash
    xattr -dr com.apple.quarantine /Applications/ReCodex.app
    ```

    У нас пока нет учётной записи разработчика Apple для нотаризации, поэтому скачанный браузером пакет получает атрибут карантина.
  </Step>
  <Step title="Войдите в ReCodex">
    Нажмите кнопку **Rx** в правом нижнем углу, откройте вкладку «Аккаунт» и нажмите **Войти в ReCodex**. Появится код авторизации — нажмите «Открыть страницу авторизации» и подтвердите в браузере.
  </Step>
  <Step title="Перезапустите один раз">
    Боковая панель сменится на ваш аккаунт сразу. Но процесс официального Codex был запущен **до** входа и не видит новую конфигурацию — поэтому нужен один перезапуск. Просто нажмите **Перезапустить сейчас** в панели.
  </Step>
</Steps>

После входа в меню аккаунта слева внизу появятся ваша почта, тариф и расход за 7 дней.

## Способ 2: командная строка

### 1. Установка

<CodeGroup>

```bash macOS / Linux
curl -fsSL https://recodex.dev/install.sh | bash
```

```powershell Windows
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://recodex.dev/install.ps1 | iex"
```

</CodeGroup>

Скрипт выбирает бинарник под платформу, **проверяет sha256** и ставит его в PATH. Если хеш не совпал — установка прерывается.

Проверка:

```bash
recodex version
```

### 2. Вход

```bash
recodex login
```

В терминале появится код авторизации и адрес; браузер откроется автоматически. Подтвердите текущее устройство.

### 3. Самодиагностика

```bash
recodex doctor
```

Проверяет по пунктам: установлен ли клиент Codex, на месте ли управляемая конфигурация, выполнен ли вход, виден ли ключ, доступен ли шлюз, активна ли подписка и работает ли Codex на самом деле.

<Warning>
  В Windows переменная окружения, записанная при `recodex login`, **не видна уже открытому терминалу** — откройте новое окно. Расширения IDE и десктопные клиенты тоже нужно перезапустить.
</Warning>

## Первые вопросы

<AccordionGroup>
  <Accordion title="Панель пишет «достигнут лимит устройств»">
    На аккаунт одновременно до 3 устройств. Отзовите ненужное в [управлении устройствами](https://recodex.dev/dashboard/devices) — **повторный вход не нужен**, опрос клиента сам пройдёт.
  </Accordion>

  <Accordion title="Установил, но интерфейса ReCodex не видно">
    Сначала убедитесь, что установлен официальный десктопный Codex. В терминале это проверяет `recodex install check` — он распознаёт и установку из магазина (MSIX).
  </Accordion>

  <Accordion title="Квота пишет «данные могут быть неактуальны»">
    Квота — это снимок с сервера. Кнопка «Обновить квоту» обновляет сразу; если данным больше 5 минут, клиент и сам делает фоновое обновление.
  </Accordion>
</AccordionGroup>
